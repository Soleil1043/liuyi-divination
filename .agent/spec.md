## 1. 问题陈述

为项目作者本人提供一个极简的六爻占卜网页：心中默念所问之事并填写下来，点击摇动三枚铜钱六次成卦，随即得到小白可读的白话解读（附《周易》原文片段），并以完整排盘供爱好者研究；卦例自动留档，可回看、可编辑、可删除。纯前端静态页面，本地存储，GitHub 开源自用。

## 3. 目标用户

- **项目作者本人（第一用户）**：日常遇到想问的事，起一卦看白话解读；偶尔回看历史卦例。不熟悉六爻术语，需要通俗解读。
- **六爻爱好者（次要，开源仓库访客）**：查看完整排盘（纳甲、六亲、六兽、世应、旬空、伏神）自行研究。

## 4. MVP 功能列表

> 每条功能必须有可验证的验收标准。不在此列表中的功能不做。

| 编号 | 功能名称 | 描述 | 验收标准 |
|------|---------|------|---------|
| F01 | 所问之事填写 | 摇卦前必须填写所问之事（如"这次跳槽好不好"），提供"今日一占"一键填入；摇卦完成后仍可编辑并保存到卦例 | ① 输入为空时无法开始摇卦；② 点"今日一占"自动填入默认文案；③ 结果页可修改所问之事，保存后历史列表同步更新 |
| F02 | 铜钱摇卦起卦 | 点击（鼠标）摇卦：每次掷出三枚铜钱定一爻，自下而上共摇 6 次；单背=少阳、双背=少阴、三背=老阳（动）、三字=老阴（动）；有摇卦动画 | ① 每次点击展示三枚铜钱正反面组合并定爻；② 第 n 次结果固定为第 n 爻（自下而上）；③ 随机结果符合概率：老阳 1/8、老阴 1/8、少阳 3/8、少阴 3/8；④ 动爻有明确视觉标记 |
| F03 | 排盘展示 | 展示完整排盘：起卦时间（公历+干支四柱）、本卦卦名/卦宫、六爻符号、纳甲干支、六亲、六兽（按日干起）、世应、旬空、伏神、变卦 | ① 给定爻值序列与起卦时间，排盘各字段与参照实现（najia 或权威在线排盘）一致；② 抽查 ≥10 个卦例（含动爻、含伏神、含旬空场景）全部正确 |
| F04 | 解读展示 | 按朱熹变占法取辞（细则见设计说明书）：白话概括在前 + 《周易》原文片段在后；含变卦提示 | ① 0～6 个动爻每类至少 1 个用例，取辞规则正确（如无动爻看本卦卦辞、一爻动看动爻爻辞、六爻全动乾坤用九用六）；② 每条解读同时展示原文与白话；③ 白话译文版权自持 |
| F05 | 历史卦例记录 | 每次成卦自动保存：时间、所问之事、六爻爻值、动爻、四柱干支、解读快照；历史列表可回看、可编辑所问之事、可删除 | ① 成卦后自动出现在历史列表；② 刷新/关闭浏览器后记录仍在；③ 可回看完整排盘与解读；④ 编辑所问之事即时生效；⑤ 删除需二次确认 |

## 5. 非目标（明确不做什么）

- **不做纳甲自动断卦**（用神、旺衰、断语生成）：规则各派争议大、易做错，排盘只展示不代断。
- **不做八字、紫微、梅花易数等其他术数**：产品定位只做六爻一事一占。
- **不做 AI 解读**：解读只来自《周易》卦爻辞与自写白话。
- **不做用户系统、云同步、多端同步**：自用，数据仅存浏览器本地。
- **不做付费、订阅、广告**：自用免费开源。
- **不做移动原生 App / 小程序**：纯网页；未来如上架可再评估（如 Capacitor 打包），不在本期。
- **不做社区、分享裂变等功能**。
- **不做历史记录导出/备份**（后续增强项，非 MVP）。

## 6. 边界与异常

| 编号 | 所属功能 | 异常场景 | 期望行为 |
|------|---------|---------|---------|
| E01 | F01 | 所问之事为空就尝试开始摇卦 | 开始按钮不可用或拦截提示，不产生半途卦例 |
| E02 | F02 | 摇卦中途刷新/关闭页面 | 未完成的卦不写入历史记录，不产生脏数据 |
| E03 | F02 | 铜钱动画未结束时快速连点 | 忽略多余点击或禁用按钮至动画结束，保证爻数不错乱 |
| E04 | F03 | 起卦时刻在 23:00–24:00（晚子时） | 采用「早晚子时」规则：晚子时日柱不进位、时柱为子时；0:00 后用新日柱。细则与验证卦例在设计说明书固化 |
| E05 | F04 | 极端卦（六爻全动、六爻全静） | 取辞规则覆盖全场景：全静看本卦卦辞；六爻全动，乾卦用"用九"、坤卦用"用六"、余卦用变卦卦辞 |
| E06 | F05 | 浏览器禁用/清空本地存储（如无痕模式） | 摇卦与解读功能不受影响，历史功能降级并提示"当前浏览器无法保存历史" |

## 7. 技术约束

- 纯前端静态网页：零后端、零服务器运行时依赖，可托管于 GitHub Pages。
- 全程在 Windows 10 上开发（Git Bash / Node 环境可用）。
- 数据仅存浏览器本地（localStorage 或 IndexedDB，选型见设计说明书）。
- **确定性**：同一爻值序列 + 同一起卦时间 → 排盘与解读输出唯一，可复现、可测试。
- 视觉效果为核心诉求（铜钱摇卦动画、逐爻成卦动效、整体国风气质）；具体风格与实现技术在方案设计阶段确定。
- 以开源协议发布（协议选型在方案设计阶段确定，倾向 MIT）；白话译文必须版权自持或公版。

## 8. 假设与依赖

- 假设：产品名「静爻」（英文标识 `jingyao`）；仓库名可沿用 `liuyi-divination` 或改为 `jingyao`，发布时定。
- 假设：所问之事默认文案为「今日一占」（F01 一键填入）。
- 假设：作者即主要用户，无多用户、多设备场景。
- 假设：清空浏览器数据会丢失历史记录，自用可接受（见非目标"不做导出备份"）。
- 依赖（外部数据/参照，构建时逐一核实）：
  - 《周易》原文：公版，取自[维基文库](https://zh.wikisource.org/zh-hans/%E5%91%A8%E6%98%93)或开源 JSON（bollwarm/ZHOUYI、js-fun/duyijing 等，核实许可）。
  - 白话译文：**以自写为兜底基线**（AI 起草全部 64 卦 + 386 条爻辞初稿，作者校对）；若核实到许可兼容的现成白话数据则替换。现代学者译本（南怀瑾、傅佩荣、黄寿祺等）有版权，不使用。
  - 装卦规则（纳甲、六亲、六兽、世应、旬空、伏神）：参照开源实现（bopo/najia，MIT）与权威在线排盘交叉验证。
- 依赖（历法）：干支四柱由公历时间推算，历法算法选型（自实现或开源库）在设计说明书确定。
